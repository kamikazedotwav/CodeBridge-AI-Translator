# Code Translator AI

An AI-powered application that translates code between multiple programming languages using Google's Gemini Flash model.

## Project Structure
- **/frontend**: React + Vite frontend application.
- **/backend**: Node.js + Express backend API.

## Setup

### Backend
1. `cd backend`
2. `npm install`
3. Create a `.env` file with your `GEMINI_API_KEY`.
4. `node server.js`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
